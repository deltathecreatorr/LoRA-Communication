# LoRA-Communication
The repository will hold the code and schematic for the devices that will communicate with radio, or any other available way to communicate such as WiFi or Bluetooth. The devices are used to communicate regardless of whether a WiFi connection is available or not.

# Parts List
- 3.5" TFT IPS LCD Display
- Seeed Studio ESP32S3
- Wio-SX1262 LoRa Wireless Module
- 3.7V 820mAH LiPo Battery
- Rotary Encoder Switch
